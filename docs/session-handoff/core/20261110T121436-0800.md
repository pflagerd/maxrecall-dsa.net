## How we work (added)

- **A change two roles must land together**: merge the other role's
  commit into core's branch unchanged, add core's on top, and say in
  the pull request that it carries both. The other role's own pull
  request closes as merged with it.
- **A test question bank is the way to try a field's other values in a
  browser**: copy the real question and its judge into a folder, change
  the field, and start a server with `MAXRECALL_QUESTIONS_DIR` and a
  users folder holding `TEST-USERS`.
