## How we work

- Everything in the pre-roles handoffs' "How we work" still applies, in
  particular: merge `master` into a pushed branch, never rebase; no
  `--force` or `--force-with-lease`.
- **One gate before every commit and push** (as users wrote it):
  `git fetch origin master`; if `master` moved, merge it in;
  `git merge-tree --write-tree --name-only HEAD origin/master` must exit
  0; only then commit, and `git push` as its own call, after reading the
  gate's result.
- **Work can land on `master` while you read.** This session found #76
  merged, and three handoffs pushed, between its first fetch and its
  first commit. Fetch again just before committing, not just at the
  start.
- Run `git fetch --unshallow origin` before comparing branches (the
  architect's note).
