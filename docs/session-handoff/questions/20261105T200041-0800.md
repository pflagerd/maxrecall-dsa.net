## How we work

- The pre-roles handoffs' "How we work" still applies: merge `master`
  into a pushed branch, never rebase; no `--force` or
  `--force-with-lease`.
- **The gate before every commit and push**: `git fetch origin master`;
  if `master` moved, merge it in; `git merge-tree --write-tree
  --name-only HEAD origin/master` must exit 0; then commit, and
  `git push` as its own call.
- **`master` moves while you work**: nine pull requests landed between
  this session's two handoffs. Fetch just before committing.
- **Edit question files as raw text**, each replacement asserted to
  match once (a short Python script in the scratchpad, run with
  `python3 -I`). Loading and re-saving the JSON would reformat the whole
  file, the one-line test cases included.
- `git fetch --unshallow origin` before comparing branches.
- **Dates differ late in a Pacific evening.** Handoffs are named in
  Pacific Time (`CLAUDE.md`), but `readme.html`'s Decisions rows have in
  practice been dated by the cloud's clock, which is UTC. That's what
  the rows show, not a written rule. #86's row says 2026-11-06, and was
  committed at 2026-11-05 19:59 PST (`d315a61`); other roles' rows
  committed 19:32–19:42 PST that evening also say 2026-11-06.
