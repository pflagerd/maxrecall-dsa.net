## Learned, and corrections

- **My correction**: the plan's item 6 said a hung test in one process
  loses every result; only if results are written at the end. Fixed in
  the plan.
- **A fresh cloud container has no bubblewrap**: `make sandbox-deps`
  installs it and libseccomp-dev, then self-tests. Until then the judge
  refuses, and the prototype stops.
- **A shallow clone gives false alarms** ("forced update"; "refusing to
  merge unrelated histories"): `git fetch --unshallow origin` first.
- **Handoff names collide**: two sessions share this folder, named to the
  second. Take the timestamp just before committing and check the name is
  free (`test ! -e`).
- **`master` moves while you push**: check `git merge-base --is-ancestor
  origin/master HEAD` before pushing a handoff; if it fails, rebase and
  check again (happened twice today).
- **Python bytecode caches** (`__pycache__/`) aren't gitignored: running
  `python3 -m unittest` in a folder leaves one to delete before committing.
