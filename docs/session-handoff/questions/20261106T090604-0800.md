## How we work

- **The gate before every commit and push**: `git fetch origin master`;
  if `master` moved, merge it in (never rebase a pushed branch);
  `git merge-tree --write-tree --name-only HEAD origin/master` must exit
  0; commit; `git push` as its own call.
- **After a merge, restart the branch**: `git merge --ff-only
  origin/master` and a plain `git push`; or `git checkout -B <branch>
  origin/master` and `git push -u origin <branch>` (not a plain push:
  Cross-boundary requests). Then check with `git ls-remote origin
  refs/heads/<branch>`.
- **Count what you write about the files with a script over them**, and
  distrust a zero: this session's first quote count found none in
  questions that have them, because the pattern was wrong. Look at the
  data's form before trusting a count.
- **Edit question files as raw text**: exact replacements in a short
  Python script in the scratchpad, each asserted to match once, run with
  `python3 -I`, writing each file only after all its replacements match.
  Re-saving parsed JSON reformats the whole file.
- **Write a new question with a generator script**: short lists inline,
  one test case per line, like the other files; check it reproduces the
  file byte for byte before editing it.
- **Run every claim before it goes in a question.** All five toolchains
  are in the cloud (`javac`/`java`, `g++ -std=c++17`, `ldc2`, `node`,
  `python3`). Judge through the real judge by calling `runSubmission`
  from a scratch script with `MAXRECALL_UNSANDBOXED=1` (cloud only,
  never the VPS), as `judge/line-numbers-test.js` does; judge a wrong
  solution too.
- **Break each new check on purpose**, and see a test fail.
- **Read a change in place before committing.**
- **External documentation sites are unreachable here**; say a link is
  unchecked rather than guess, and list it in the pull request.
- **Show a command's whole output** when it decides something: `| tail
  -1` hid this session's push refusal.
- `git fetch --unshallow origin` before comparing branches.
