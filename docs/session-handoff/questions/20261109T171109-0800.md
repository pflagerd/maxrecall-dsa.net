## Facts checked by running, worth keeping

- **A deny-list over JavaScript leaks.** Each review found more ways
  round it:
  - `Object.getOwnPropertyDescriptor(Object.getPrototypeOf(module), 'req'+'uire')`
    reaches `require`, which lives on `Module.prototype`;
  - `({}).__lookupGetter__('__proto__')` gets a prototype;
  - `RegExp.input` held a token tested before;
  - `const M = Math; M.max = …` changed `Math.max` everywhere.
- **TypeScript treats `Math.max = …` in a `.js` file as declaring
  `Math`** (its "expando" assignments). Count only real declarations.
- **In strict mode, V8's stack-trace API** (`Error.prepareStackTrace`)
  gives no functions or `this`.
- **Node keeps a `require`d file's first-loaded code until a restart**,
  so a file's hash has to be taken at load.
- **The quote question on Python 3.13.18**:
  - `'` and `\'` print the same;
  - curly quotes print with no error;
  - `"'"` and `"` are syntax errors.
