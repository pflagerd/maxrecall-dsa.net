## How we work (architect)

- **Cloud checkouts are shallow**: run `git fetch --unshallow origin`
  before comparing branches, or merged branches look unmerged (the last
  handoff's session nearly reported 45–80 "missing" commits on a dozen
  merged branches).
- The architect doesn't push to `master`: its handoffs go through pull
  requests too.
- The older git rules hold: fetch `master` before every commit and stop
  if it moved; merge `master` into a pushed branch, never rebase;
  `git push` as its own step; `git merge-tree --write-tree --name-only
  HEAD origin/master` (exit 0) before a pull request.
- Contracts: name things by identifiers in the code, not line numbers,
  and leave signatures to the provider's JSDoc. A `require` scan finds
  imports across roles but not strings matched by value, URL paths or
  ports: read for those too.
