When handoff names change from `-0800` to `Z`, a UTC name sorts 8 hours
(7 in daylight saving time) later than a Pacific one for the same moment.
So "the newest is the last by name" (`CLAUDE.md`) can pick the wrong file
around the switch unless the old names are renamed, or the first UTC one
is written at least that long after the last Pacific one. The readme's

## How we work (architect)

- **Commit a handoff on a branch started from `origin/master`**, never on
  a branch with unmerged work: `git push origin HEAD:master` pushes every
  commit the branch has. This one went that way, on
  `architect-handoff-tmp`, deleted after.
- **After a merge, restart the branch at `master`** (corrected,
  questions' `20261106T090604-0800.md`): `git checkout -B <branch>
  origin/master` makes `origin/master` the branch's upstream
  (`branch.autoSetupMerge`, default `true`), and a plain `git push` then
  refuses under `push.default=simple` ("The upstream branch of your
  current branch does not match the name of your current branch";
  reproduced, git 2.43.0). Use either:
  - `git merge --ff-only origin/master`, then `git push`. Recommended.
  - `git checkout -B <branch> origin/master`, then `git push -u origin
    <branch>`.

  Then `git ls-remote origin refs/heads/<branch>`; `git status -sb`
  shows the upstream (`<branch>...origin/master` means it's wrong).
- **Check `master` hasn't moved before pushing a handoff**: it moved
  (#106) while this one was written, and the chained check stopped the
  push. Rewrite the handoff on a fresh branch from `origin/master`.
- **Try a merge order in a throwaway worktree**: `git worktree add
  --detach <dir> origin/master`, merge each branch in turn (`git merge
  --abort` on a conflict), then `git worktree remove --force <dir>`.
  Nothing is pushed.
- **A `require` scan misses code in strings**: `routes.test.js` requires
  `auth.js` inside a `node -e` script. Search for module names as text
  too.
- **Check a role's claim about another role's code against the code**;
  **ref names with `/` break `sed s/…/…/`** (use `s|…|…|`, and distrust
  a diff that says everything changed).
- From before, still true: `git fetch --unshallow origin` before
  comparing branches; judge ownership by the rules in force at the
  commit's time; retry a push that GitHub refuses (`commit_refs`); edits
  by script assert each replacement matches once; contracts name
  identifiers, not line numbers (this file's are a snapshot), and search
  strings, paths and globals a `require` scan can't see.
