## How we work (architect, this session)

- **Cloud checkouts are shallow** (`git rev-parse
  --is-shallow-repository` said `true`). Comparing branches in one shows
  false "unmerged" commits: here it reported 45–80 for a dozen branches
  that are fully merged, because their history stops where the clone
  does. Run `git fetch --unshallow origin` before comparing branches.
- The architect doesn't push to `master` (`architect.md`): its handoff
  goes through a pull request too.
- The old handoffs' git rules still hold: fetch `master` before every
  commit and stop if it moved; merge `master` into a pushed branch, never
  rebase; `git push` as its own step; `git merge-tree --write-tree
  --name-only HEAD origin/master` (exit 0) before a pull request.
- A list of who owns what is easiest checked mechanically: match
  `git ls-files` against the Owns lists and count each file's owners
  (exactly one each). This session's check was a shell script in its
  scratchpad, not in the repo.
