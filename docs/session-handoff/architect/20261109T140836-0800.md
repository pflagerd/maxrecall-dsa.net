## How the owner likes a topic explained: "bite-size-pieces" (owner, 2026-11-09)

The owner asked for R1's full context "in bite-size pieces", to confirm
understanding before moving on, the size to be found as we went. Over
17 pieces, every one was judged "just right". Then: "I think we're done
with the bite-size piece thing. You've got it." What worked, for the
next architect:

- **Label each one "bite-size-piece N"**, the owner's own term. (The
  architect first wrote "Piece 1", an undefined label of its own; the
  owner asked what it meant.)
- **One idea per piece**, about a screen: what it is, one concrete
  example (a code line, a quoted rule, a test result), and where it's
  recorded (the issue, file and line).
- **Start from the issue** the topic belongs to, and define every term
  the first time it's used. "fill-in" went undefined in piece 2 and the
  owner asked; that led to the rename to "fill-in-the-blank".
- **End with "too big, too small, or about right?"** and, where it
  helps, "in your own words…" (the owner found the question useful even
  when not answering it).
- **A decision goes in its own piece**: the options, a recommendation,
  then the question.
