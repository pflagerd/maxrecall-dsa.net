## Later: UTC (owner: "migrate everything to UTC eventually. Leave it alone for now.")

When handoff names change from `-0800` to `Z`, a UTC name sorts 8 hours
(7 in daylight saving time) later than a Pacific one for the same moment.
So "the newest is the last by name" (`CLAUDE.md`) can pick the wrong file
around the switch unless the old names are renamed, or the first UTC one
is written at least that long after the last Pacific one.

## How we work (architect)

- **Check a role's request against the code before writing it into a
  contract**: questions' request named the wrong file for three fields
  and missed one dependency; both showed up only by reading
  `routes.test.js` and `routes.js`.
- **A rename can collide with a cleanup**: before renaming anything the
  deploy installs, search the script for the new name too (#123's
  `OLD_UNIT`).
- **Commit a handoff on a branch started from `origin/master`**, never on
  a branch with unmerged work: `git push origin HEAD:master` pushes every
  commit the branch has. Check `master` hasn't moved just before pushing;
  if it has, rewrite on a fresh branch from it. Copy only the handoff
  file across: `git reset --soft` onto the new `master` would keep the
  old tree and undo the merge that moved it.
- **After a merge, restart the branch**: `git merge --ff-only
  origin/master`, then `git push`. Check with `git status -sb`.
- **Resolving a `readme.html` conflict** where both sides add: keep both;
  check that one side's "Last updated" line is the other's with only
  entries prepended before taking it; compare the result with `master`,
  where only your own entry and row should differ. Merge, never rebase, a
  pushed branch.
- **What visitors see** is what `server.js` serves (`STATIC_FILES`) and
  what the app sends people (the invite message).
- **A session's account of where it runs is a claim, not a fact**: look
  for evidence (its handoff's `hostname`/`id`, its commits' paths), or
  say it's unchecked.
- **A listing cut short isn't an absence**: this session's first `ls |
  head -100` hid the operator's second handoff; it was there.
- **Search the code, not a role's account of it**; **a `require` scan
  misses code in strings**; **a filter can hide what it's searching
  for**.
- **Who wrote a branch with no handoff**: a commit's `Claude-Session`
  trailer, compared with other commits' (`git log --grep=<session id>`).
- **Try a merge order** with `git merge-tree --write-tree --name-only A
  B` (exit 1 and the file names on a conflict), or in a throwaway
  worktree.
- From before, still true: `git fetch --unshallow origin` before
  comparing branches; judge ownership by the rules in force at the
  commit's time; retry a push GitHub refuses (`commit_refs`); edits by
  script assert each replacement matches once; contracts name
  identifiers, not line numbers (this file's are a snapshot).
