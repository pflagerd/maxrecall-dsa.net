## How we work (this session's additions)

- **Prove a test can fail**: break the code it guards in a copy, one way
  at a time, and see the test named for it fail. A runner that copies the
  repository (minus `.git`, `node_modules` symlinked), applies one exact
  replacement (refusing unless it matches once) and runs the test file is
  quick to write; this session's was a scratchpad file, not kept. Its
  seven breaks are listed above, to redo by hand.
- **A test that spawns a process stops it on every failure path**, or a
  failure becomes a hang.
- **`fetch()` normalizes paths** (`/%2e%2e/server.js` becomes
  `/server.js`), so traversal probes use `http.request`, which sends the
  path as given.
- **`MAXRECALL_UNSANDBOXED=1` never turns a working sandbox off**
  (`judge/sandbox.js`, its comment), so a test may set it on any machine.
