## Lessons for the next users session

- **Look file names up, don't write them from memory**: twice today a
  handoff draft named a handoff that didn't exist (caught before
  pushing).
- **Re-read an issue before drafting from it**: the records plan missed
  #160's Q6.4 because #160 had changed since it was first read.
- **In the cloud, `cdnjs.cloudflare.com` is blocked**: the problem page's
  editor (CodeMirror) and KaTeX never load there, so checking the editor
  in a browser needs the owner's machine.
- **A plain push suffices after restarting the branch from `master`**:
  the old tip is already in `master`, so it's a fast-forward; the auto
  mode check refuses `--force-with-lease`.
- **`make characterize` records keys and value types**, not values or
  key order: for a "changes nothing" refactor of a response, compare
  the full bodies too.
