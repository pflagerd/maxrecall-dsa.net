## Done: #102, the idle timeout

Owner's decisions (#102's comment, and asked this session):
- an hour in all: a "Still there?" warning after **55 minutes** with no
  keyboard or mouse input, a **5-minute** countdown, then the question
  list;
- **real time**, hidden tab or not, but **a warning begins only while the
  tab is visible**: a tab hidden past 55 minutes shows the whole 5:00 when
  it's next shown. Once begun, the countdown runs in real time (my small
  choice: it has been seen);
- nothing recorded; the editor's code is lost;
- in **`timer.js`** (`createIdleTimeout`, beside the stopwatch), so
  nothing from another role was needed to ship it.

Decided while building (small choices, in `docs/plans/elapsed-timer.md`,
"The idle timeout"): input is `keydown`, `pointerdown`, `pointermove` and
`wheel` on `window`, capture phase; checked once a second and on
`visibilitychange`; leaving is `location.assign('/')`.

**Found while checking, for the owner**: since mouse movement counts as
input, reaching for "I'm still here" closes the warning before the click
lands (Playwright's click failed on exactly that). The button is for a
tap or the keyboard. If the owner would rather the warning needed a
deliberate click or key, `pointermove` would still reset the idle time
but no longer close the warning: a small change in `onIdleInput`.
