## How we work (this session's additions)

- **Check where you are before running anything that can stop, start or
  install** (`hostname`, `id`, `get_session`'s `environment_kind`). A
  system prompt's description of the environment isn't evidence.
- **Never `pkill -f` or `killall` by pattern.** Stop your own processes
  by the PID you started, after checking `/proc/<pid>/cmdline`.
- **Don't run a server or tests on a machine that runs the service.**
- When a claim of yours turns out wrong, find every handoff that repeats
  it and correct it where readers will look first.
