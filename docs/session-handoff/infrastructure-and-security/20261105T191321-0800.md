## How we work (this session's additions)

- **Chain every step after a `master` check with `&&`.** Here the check
  stopped one commit when `master` moved (#81), but a second
  `git add`/`git commit` not chained to it ran anyway. Nothing was
  pushed; `git reset <base>` (mixed: keeps the changes) and committing
  again put it right.
- **No `node -e '…'` with an apostrophe in it.** One in a comment ends
  bash's single quotes early; the script then runs truncated, silently.
  Write a script file with a quoted heredoc (`<<'EOF'`) instead.
- **nginx in the cloud:** `apt-get install nginx` gives 1.24.0, as on the
  VPS; run it with `nginx -p <dir> -c <dir>/nginx.conf`, `user root;`
  (the scratchpad's parents are `drwx------`), and temp paths in the
  folder. `curl --interface 127.0.0.N` makes requests come from different
  addresses (all of `127.0.0.0/8` is loopback). There's no IPv6 at all in
  the container, so feed IPv6 text to a `map` through `$arg_…`, which
  **nginx doesn't URL-decode**: send `:` as it is, not `%3A`.
- **Read the plan's decision log before asking the owner** about the VPS
  or DNS: it had the AAAA check this session asked for again.
- **Test a test** by removing what it guards: done for each of #80's
  tests and for the map's middle regex.
