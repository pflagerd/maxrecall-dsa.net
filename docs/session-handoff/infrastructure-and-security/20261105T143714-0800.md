## How we work (this session's additions)

- **Review in a worktree**: `git worktree add --detach <dir> <sha>`
  checks a pull request's exact commit out in another folder, so the
  session's own branch is untouched. `git worktree remove` afterwards.
  `npm install` there (not `npm ci`: no lockfile); a second worktree can
  share it with `ln -s <first>/node_modules`.
- **Test the test**: before trusting "identical" from a check, break the
  thing it guards in a scratch copy and see it fail.
- This repository is public: no details of other repositories'
  weaknesses, or of the VPS's addresses, in files here.
