## How we work (this session's additions)

- **Cloud containers put Node 18 first on `PATH`**
  (`/root/.local/share/node-v18.17.0-linux-x64/bin`, not from
  `~/.bashrc` or `~/.profile`, so probably the image). `toolchain-deps`
  refuses, as it should. Work around per command with
  `export PATH=/usr/local/bin:$PATH` (Node 22.23.4 there). Not fixed:
  the SessionStart hook could do it, but a hook's `export` doesn't
  reach later commands, so it would need `CLAUDE_ENV_FILE` (a guess
  from the hooks docs; not checked).
- **No GitHub tools for pull requests in some cloud sessions**:
  ToolSearch found no `mcp__github__*` here. Push the branch and give
  the owner the compare URL.
- **Keep commands small and single-purpose**: chained `cd … && export …
  && …` commands and inline scripts can't be allowlisted, and they were
  most of this session's permission prompts.
