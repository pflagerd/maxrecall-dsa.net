## How we work (found since the last handoff)

- **A test that is meant to exit non-zero under systemd leaves a failed
  unit**: use `systemd-run --collect`, and check `systemctl
  is-system-running` after any procedure, not only before.
- **In a cloud session, check that the repository's hook ran** before
  relying on what it installs: `command -v bwrap`. With more than one
  repository attached, it doesn't.
- **A helper's summary of a web page isn't the page**: say which it was
  when citing it.
